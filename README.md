# ReviewPilot

A data and AI pipeline on Berlin short-stay data: Airflow loads listings and guest reviews into a MariaDB warehouse, Metabase shows the trends, and a Claude agent answers questions through fixed tools.

**Stack:** Python, SQL, MariaDB, Apache Airflow, Metabase, Docker Compose, Claude API

**Status:** in progress. Built as a learning project, using Claude as a mentor for explanations and code review.
